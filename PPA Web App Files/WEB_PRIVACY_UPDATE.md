# Privacy Policy Update for the PPA Web App

Before the standalone web app is made available to contractors, update the existing PPA privacy page so it reflects the web version in addition to the ChatGPT plugin.

Suggested language to add or adapt:

## PPA Web Assessment

Strategic Visibility may also provide the Premium Positioning Architect through a standalone web assessment. In that version, users provide business information directly through a Strategic Visibility-hosted interface. The information is transmitted to OpenAI's API to generate assessment questions, maintain the positioning assessment, and produce the Strategic Positioning Blueprint.

The initial version of the web assessment does not require a user account and does not intentionally collect contact information as part of the positioning workflow. Assessment progress is stored locally in the user's browser so the user can resume the assessment on the same device. Strategic Visibility does not maintain a separate database of assessment answers in the initial version.

Requests to the assessment are processed through Strategic Visibility's web hosting infrastructure and the OpenAI API. Users should not provide passwords, payment card information, government identifiers, protected health information, or other unrelated sensitive personal information.

If Strategic Visibility later adds account login, cross-device storage, email delivery, analytics tied to individuals, CRM integration, or another persistent storage system, this policy will be updated before those features are released.

## Service providers

The standalone PPA may rely on service providers necessary to host and operate the assessment, including the web hosting provider and OpenAI for AI processing. Their handling of information is governed by the applicable agreements and privacy terms for those services.
